# Contributing to Formatflux

¡Gracias por considerar contribuir a Formatflux!

## Cómo Contribuir

### Reportar Bugs
- Usa GitHub Issues
- Incluye ejemplo reproducible
- Describe el comportamiento esperado vs actual

### Sugerir Features
- Abre un Issue con el label "enhancement"
- Describe el caso de uso
- Propón una solución técnica

### Código

1. **Fork el repositorio**
2. **Crea una rama**: `git checkout -b feature/nueva-funcionalidad`
3. **Commit**: `git commit -m "feat: agregar nueva funcionalidad"`
4. **Push**: `git push origin feature/nueva-funcionalidad`
5. **Pull Request**

## Convenciones

### Código
- Usar type hints
- Documentar funciones con docstrings
- PEP 8 compliance (usar black/ruff)
- Tests para nuevas funcionalidades

### Commits
- Usar Conventional Commits
- Ejemplos: `feat:`, `fix:`, `docs:`, `test:`

### Testing
```bash
pytest tests/
```

## Code of Conduct

Por favor, mantén un ambiente respetuoso e inclusivo.
